# TeamBeacon

Engineering Operations Command Center

A real-time dashboard for engineering teams that integrates Jira, voice announcements, live team status, DevOps metrics, and cloud-native deployment.

## Vision

To provide a single large-screen operational dashboard that gives engineering teams instant visibility into work, deployments, incidents, and sprint health.

## Tech Stack

- React
- Node.js
- TypeScript
- PostgreSQL
- Redis
- Docker
- Kubernetes
- Prometheus
- Grafana
- AWS
